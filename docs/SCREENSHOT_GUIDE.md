# Screenshot guide

Use the existing evidence dimensions as the browser viewport, capture the visible page region, and save PNG files in `public/images/before-after/`.

| File | Viewport | Page/region | Must be visible |
|---|---:|---|---|
| `new-menu.png` | 1115×607 desktop | `/menu`, top of menu | Search field, category filters, category image and items |
| `new-navbar.png` | 1115×607 desktop | `/menu`, categories area | All category controls and the category hero below them |
| `new-menu-card.png` | 1115×607 desktop | `/menu`, a selected category | Category name, image, and first row of item cards |
| `new-navbar-mobile.png` | 390×844 mobile viewport (current supplied capture: 780×1688 pixels) | `/menu`, top of menu | Header, search, wrapped category buttons, and image start |

For consistent evidence, use 100% browser zoom and capture the page content without browser chrome. The desktop source evidence is 1115×607 pixels; mobile source evidence dimensions differ, so keep the actual viewport noted with the final capture.
